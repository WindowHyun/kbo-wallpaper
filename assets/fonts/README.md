# 번들 글꼴

외부 CDN 장애가 서비스 장애로 이어지지 않도록 렌더링에 쓰는 글꼴을 저장소에 직접 포함한다.
([lib/fonts.ts](../../lib/fonts.ts) 에서 로드)

| 파일 | 글꼴 | 출처 | 라이선스 |
| --- | --- | --- | --- |
| `Pretendard-Regular.otf`, `Pretendard-Bold.otf`, `Pretendard-ExtraBold.otf` | Pretendard 1.3.9 | npm `pretendard` (github.com/orioncactus/pretendard) | SIL OFL 1.1 |
| `NanumPenScript-Regular.ttf` | 나눔손글씨 펜 | npm `@expo-google-fonts/nanum-pen-script` (네이버 나눔글꼴) | SIL OFL 1.1 |

두 글꼴 모두 SIL Open Font License 1.1 로 배포되어 임베딩·재배포가 허용된다.
